# Security Appliance 1.0 GA

The GA build is sealed from a validated appliance, removes deployment state and credentials, overwrites free OS blocks, attaches a fresh blank data disk, clears staging OVF values, and exposes masked deployment properties.

Qualification covers clean first boot, standard sign-in, static networking, DNS and NTP health, firewall isolation, all six service tests, trusted certificate enrollment, HTTP-to-HTTPS redirection, proxy policy, signed update and restore, reboot persistence, fixed-function console recovery, and VMware vCenter KMIP encryption.

Verify the OVA with the adjacent SHA-256 file before import.
