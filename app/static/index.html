Deployment
Supply separate credentials and stable DNS names during OVA import. Sign in at /admin/, complete the five steps and resolve required preflight findings. Replace the temporary HTTPS certificate with a matching CA-signed certificate and chain.
Administration and recovery
Use Health Status and bounded diagnostics before making changes. Each service page owns its controls and test history. Network changes require reconnection confirmation. The fixed-function VM console can reset an existing web administrator without Ubuntu shell access.
OIDC and KMIP onboarding
Register exact redirect URIs, audiences and roles in Keycloak; browser clients use Authorization Code with PKCE. Generate KMIP keys and CSRs on the consumer, sign only the CSR on the appliance, approve its source network and test a disposable encrypted workload.
Proxy, updates and troubleshooting
Use explicit trusted upstreams for reverse proxy routes. The optional forward proxy allows approved client egress without TLS interception. Review the relevant service log and diagnostics, then download a support bundle. Signed updates retain one qualified prior release for a guarded restore.
